# CS350
A collection of work done in Emerging System Architecture &amp; Technology class

&nbsp;&nbsp;&nbsp;&nbsp;The project was building a smart thermostat and programming the internal logic to function and communicate with peripherals. This involved installing peripherals, installing and programming LED indicator lights, setting up temperature sensors and a display monitor, and setting up buttons to effect changes in system state and set temperatures. After the prototype was built, I documented the state machine with a state diagram and researched various integrated solutions for a production ready model. The project provided a solution for a Wi-Fi-enabled smart thermostat, that could not only be manipulated through button presses and display current information but could communicate that information to a server through an UART interface.  
&nbsp;&nbsp;&nbsp;&nbsp;What I did particularly well was implementing the logic by writing clean and maintainable code. I found programming to be the most straightforward task in the project as requirements were clear and understandable. However, there were a few aspects where I could improve. My understanding of the state diagrams was limited, and I constantly found myself unsure of the extent of what to include. This required me to constantly reference Moore and Mealy diagrams online, as well as reach out to the professor for clarification. My concern was crowding the diagram with too much irrelevant information or leaving out crucial aspects that should be included. At this point, I have a clearer view of what should be included, although it was definitely a facet I could use more practice with. In addition, I also struggled consistently with hexadecimal and binary conversions. While this was not as relevant to graded material, its use earlier in the course illuminated to me a skill that needs strengthening before I am sufficiently confident. Although in the course of the class, I found some helpful sources with methods for breaking down these conversions, which will help me going forward.

&nbsp;&nbsp;&nbsp;&nbsp;This course necessitated reading more documentation and reading reference examples online, so going forward I will add to my tool set the tools of utilizing such sources when building fundamental skills in unfamiliar technologies. 

&nbsp;&nbsp;&nbsp;&nbsp;Throughout this course, I have added to my skillset the ability to understand and write clean, effective state machines, as well as the fundamentals of working with physical computer hardware. In addition, my Python skills have widened, and I feel more confident working with the various libraries we utilized in this course, namely Python’s statemachine and GPIOzero libraries. 

&nbsp;&nbsp;&nbsp;&nbsp;I made this project maintainable, readable, and adaptable by adopting good practices when implementing code. Code was written according to separation of concerns, making each method an individual logical action that could be adapted with limited modification to surrounding code. I also documented my code well, so future developers, myself included, can easily read through the source code and understand what each method achieves. This extends to naming conventions and the accompanied state diagrams, which provide additional context for future developers to easily understand the code base and expand on it, or modify it for other purposes.
